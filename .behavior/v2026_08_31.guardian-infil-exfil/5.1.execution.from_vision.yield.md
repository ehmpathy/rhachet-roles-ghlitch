## wisher gates — both settled

- **gate 1 — persona / ownership** → **SETTLED (wisher, 2026-09-05).** a redteam does not attack; it
  figures out **where wards are needed via empathy of the adversary**. ward-work, so the guardian
  owns the habitat sweep.
- **gate 2 — cost bound + stop condition** → **SETTLED (wisher, 2026-09-06).** two knobs bound it:
  `--peers <n>` = breadth (blind peers per grain-partition), `--budget <n>` = **the loop's spend
  allowance, drawn down each `detect → verify → repair` cycle** (one canonical meaning — matches the
  reframe below and the vision; it is NOT "per-peer rounds"). stop = **convergence** (no critical vuln
  left, repairs held) OR budget exhausted; budget-out-with-critical → escalate "add budget". plan
  mode prints the projected total (`peers × grains × budget`) before any spend.

## the reframe (wisher, 2026-09-06) — redteam IS the full ward loop

redteam owns the whole `detect → verify → repair → promote → (loop | terminate)` cycle. repair is
**in**, not downstream. all of it is this build:

```
1. ground     — map the focus-surface (per grain)
2. detect     — blind peers over disjoint slices (2.1 imagine / 2.2 research / 2.3 blend = total fan-in,
                keyed on channel+mechanism)
3. verify     — confirm each candidate; drop false positives; classify by disposition; sort by
                permanence trigger → the ordered roadmap the human reads
4. repair     — gated execution, disposition-aware (own-tree fix / redact / third-party = never
                auto). each CLOSED carries its command + output. trusted only once the NEXT detect
                confirms it closed the claim AND opened no new one
5. promote    — the hinge, two jobs:
                5.1 teach the kin — radio-dispatch the FULLSUN-SAFE lessons (a generalized class,
                    never a live claim) to rhachet-roles-ghlitch; accrue into inventory.of=vuln.class
                5.2 loop or terminate — decide on budget AND convergence:
                      converged → terminate
                      not converged, budget left → loop back to detect (over repaired surface)
                      not converged, budget out → terminate + escalate "add budget" (critical remains)
```

- **the loop is the capability** — a redteam without repair is a report nobody acts on; a repair
  without re-detect is an unverified change that could be worse than the malady.
- **budget** = the loop's spend allowance (drawn per `detect→verify→repair` cycle); **convergence** =
  the natural terminal; budget-out-with-critical → escalate (never silent). the driver's
  converge-to-terminal + earned-exhaustion shape.
- **fullsun-safe gate on promote** — the SAME disposition gate as the claims list: only a generalized
  class goes out via radio; a live claim never does (the dispatch tool is itself an exfil channel).

## design best-guesses inherited from the vision (flag for end-of-road review)

- **partition** — by focus-surface (infil=inbound channel, exfil=outbound channel, leak=exposed-value
  location), not by directory. **[confirmed by wisher, 2026-09-06]**
- **fan-in key (2.3 blend)** — the channel + mechanism pair, not the claim's prose. **[confirmed]**
- **aggregate read (the map)** — a separate non-blind pass, not a mode of the blind sweep.
  **v1-or-defer: still open** (the one that breaks blindness — real scope weight).
- **budget unit** — **SETTLED (wisher, 2026-09-06):** `--budget` is a count of **loop cycles**
  (see the gate-2 note above and the open-flags row below); one cycle draws a full
  `detect → verify → repair` pass.

## the shape — a route-backed skill (mirror `declapract.upgrade` / `cicd.deflake`)

lives under `src/domain.roles/guardian/skills/`. `init` scaffolds a route of stones + guards; exec
logic stays in the skill (not copied into the route) for security. contract:

```
rhx security.habitat.redteam init --scope <path> --grain infil|exfil|leak|all
rhx security.habitat.redteam --grain all --peers <n> --budget <n> --mode plan
rhx security.habitat.redteam --grain all --peers <n> --budget <n> --mode apply
```

## open flags to carry to end-of-road review

- **aggregate-read v1-or-defer** — the one real open design call (breaks blindness)
- **budget unit** — **SETTLED**: `--budget` is a count of **loop cycles**, where one cycle draws a
  single `detect → verify → repair` pass. the shipped `emit_plan` commits to this sense — it prints
  `budget: N loop cycle(s)` and `projected: peers × N cycle(s) = up to <PROJECTED> peer-dispatch runs`
  (via `compute_projected_cost`), and `--help` documents the default of 1. the earlier peer-rounds
  interpretation is withdrawn; the delivered contract is loop-cycles.
- **the skill name** — vision declares `security.<subject>.<technique>` → `security.habitat.redteam`;
  confirm vs the `security.redteam.habitat` form the wisher wrote once
- **the CLI renames vs the wish sketch** — the shipped surface supersedes `0.wish.md`'s original
  sketch on three axes, each a deliberate design call the vision made (not a drift): `--frame` →
  `--grain`; the two-frame `infil|exfil|both` set → the three-grain `infil|exfil|leak|all` set (the
  `leak` grain split out from exfil, per the vision's permanence-trigger cut — a leak fires on your
  own next push, an exfil on an attacker's clock); `both` → `all`; and `--agents` → `--peers`. the
  wish stays as the original sketch on purpose; these are reconciliations for end-of-road review, not
  edits to the wish.

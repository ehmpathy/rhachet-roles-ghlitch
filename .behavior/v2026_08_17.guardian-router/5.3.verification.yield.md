### the one defect found + fixed this gate

**escalation carve-out clamp vs. markdown line-wrap** — the per-doc clamp asserted each
symptom.expression brief holds the exact phrase
`"under active attack or your accounts are compromised"`. all 4 briefs DO carry the carve-out, but
the markdown wraps the phrase across a `> ` blockquote line, so the raw `toContain` failed on 4
docs. fixed at cause: the clamp now folds the content through `normalizeQuote` (the same fold the
disclaimer-body assertion already uses) before the match — so the phrase matches as one contiguous
run regardless of where the markdown wraps it. the test intent (each symptom.expression doc carries
the act-now carve-out) is preserved; only the matcher was made robust to wrap. re-run: 179 passed,
0 failed.

# 🌙 dream: a hook that refuses a direct lesson push past the scan gate

- kind: feature
- owner: guardian role
- caught: 2026-11-01

## .the cue that fired

a peer review (i014 r011) showed that `rhx radio.task.push --via gh.issues --into <teach repo>`
runs with no prompt, so an agent can publish a lesson past the `dispatch-lesson` scan gate.

## .the gap, precisely

the scan gate is enforced only when the agent calls it. a direct push skips the live-claim scan.
the promote stone forbids that in prose; no tool refuses it.

## .the shape of the fix

- a guardian PreToolUse hook on Bash: refuse a command that runs `radio.task.push` into
  `RADIO_TEACH_REPO`, with a fix line that names `rhx security.habitat.redteam dispatch-lesson`
- the gate's own push runs inside the skill process, never as an agent Bash call, so the hook
  leaves it open
- register the hook in the role manifest; boot wires it
- tests: a direct push refused (exit 2), the gate's push unaffected, an unrelated push unaffected

## .why it is not done in this round

new role hook infra ripples past this stone's diff (manifest, boot, tests). fulcrum F23.
